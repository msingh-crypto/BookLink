# BookLink

A campus-only marketplace for buying and selling used textbooks among Lakehead University (Thunder Bay) students.

## Problem

University textbooks in Canada are expensive, with many students spending $1,000–$2,500+ per year on course materials. At Lakehead, current options (Facebook groups, general classifieds, bookstore buybacks) are fragmented, not campus-specific, and lack trust and relevance.

## Solution

BookLink is a web application that verifies student status (e.g., via Lakehead email), hosts book listings organized by course/ISBN, and facilitates direct communication and local, on-campus transactions.

## Core Features

- Student registration and verification (Lakehead email)
- Create and browse book listings (title, edition, course code, price, condition, photos)
- Search and filters (by course, keyword, ISBN)
- In-app messaging between buyers and sellers
- Mark items as sold/purchased; optional feedback/ratings
- Safety guidance for on-campus meetups
- Moderator and administrator tools for content and user management

## Primary Users & Roles

- **Guest:** Browse public listings and search results; prompted to register to contact sellers or post listings.
- **Customer (Student Buyer/Seller):** Register/log in; create/manage listings; search/filter; view details; message others; mark sold/purchased; leave feedback.
- **Moderator (Student/Staff):** Review reported listings/users; remove inappropriate/fraudulent content; suspend/flag accounts; enforce safe trading guidelines.
- **Administrator:** Manage roles/permissions; configure site settings; view analytics; handle escalations.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript, React  
- **Backend:** Node.js  
- **Database:** PostgreSQL  

## Value

- Lowers textbook costs by expanding access to used books (typically 30–70% cheaper than new)
- Keeps transactions local and trusted within the Lakehead community
- Saves students time finding the right edition
- Sellers recoup part of their investment; buyers pay less; books circulate on campus instead of being discarded
